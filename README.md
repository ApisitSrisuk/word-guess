# 🎉 เกมปาร์ตี้กับเพื่อน

เข้าห้องเดียวกันด้วยชื่อ + รหัสห้อง แล้วหัวห้องเลือกเกม (ทุกคนเห็นว่าเลือกเกมไหน):

- 🎯 **ทายคำ** — ทุกคนได้คำลับไม่ซ้ำกัน เห็นแค่คำตัวเอง แล้วผลัดกันทายคำของเพื่อน
- 🕵️ **ใครคือสปาย** — ชาวบ้านได้คำเดียวกัน สปายได้คำคล้าย ผลัดกันใบ้แล้วโหวตจับสปาย
- ❓ **ทายคำตรงกลาง** — สุ่ม 1 คนเป็นคนตอบ (เห็นคำลับคนเดียว) ที่เหลือผลัดกันถามใช่/ไม่ใช่ แล้วแข่งกันทาย
- 🧀 **หัวขโมยชีส** — ทอยเต๋าลับ กลางคืนตื่นตามเลขเต๋า 1 คนแอบขโมยชีส ตอนเช้าคุยแล้วโหวตจับขโมย
- 🎨 **วาดภาพทายคำ** — ผลัดกันวาดบนจอ คนอื่นเห็นเส้นแบบสดแล้วแข่งกันพิมพ์ทาย
- 🟥🟦 **Codenames** — 2 ทีม หัวหน้าใบ้ 1 คำ + ตัวเลข ลูกทีมเปิดการ์ดสีทีมตัวเองให้ครบก่อน ระวังนักฆ่า
- 🎲 **เต๋าโกหก** — เต๋าลับคนละ 5 ลูก ผลัดกันประกาศว่าทั้งโต๊ะมีเลขอะไรกี่ลูก หรือกด "โกหก!" ใครเต๋าหมดตกรอบ

การถาม-ตอบ (ทายคำ และ ทายคำตรงกลาง): คนตอบกดได้แค่ **✅ ใช่ / ❌ ไม่ใช่ / 🤔 อาจจะ** — ถาม-ตอบทั้งหมดขึ้นบนจอให้ทุกคนอ่าน

ทุกเกม: หัวห้องตั้ง **เวลาต่อตา** ได้ 30 วินาที – 2 นาที (หรือไม่จับเวลา) หมดเวลา = ข้ามตา
แชทจะ **ล้างทุกครั้งที่เปลี่ยนตา** และบนคอม (จอกว้าง) แชทเปิดค้างไว้ด้านขวาตลอด

## Deploy บน Render (สิงคโปร์)

เกมใช้ Socket.IO ส่งข้อมูลสด จึงต้องใช้เซิร์ฟเวอร์ที่เปิดค้างไว้ — Render รองรับ และมีโซนสิงคโปร์ (ใกล้ไทย)

1. สมัคร/ล็อกอิน [render.com](https://render.com) ด้วย GitHub
2. **New → Blueprint** → เลือก repo `word-guess` → Render อ่าน `render.yaml` แล้วตั้งค่าให้เอง (โซนสิงคโปร์, แพ็กเกจฟรี)
3. กด **Apply** รอ build ~2 นาที จะได้ลิงก์ `https://word-guess-xxxx.onrender.com`
4. หลังจากนี้ `git push` ทุกครั้ง Render จะ deploy ให้อัตโนมัติ

แพ็กเกจฟรี: ถ้าไม่มีคนเล่น 15 นาทีเซิร์ฟเวอร์จะหลับ — คนแรกที่เปิดต้องรอ ~50 วินาที (เปิดลิงก์ทิ้งไว้ก่อนเริ่มเล่นสักนาที)
และเมื่อเซิร์ฟเวอร์หลับ/deploy ใหม่ ห้องที่ค้างอยู่จะหายไป อยากให้ไม่หลับ → เปลี่ยนเป็น Starter ($7/เดือน)

## รันในเครื่อง

```bash
npm install
npm start
```

เปิด `http://localhost:3456` — เพื่อนที่อยู่ Wi-Fi เดียวกันเข้าผ่าน IP ที่แสดงใน console
ทดสอบ: `npm test`

## วิธีเล่น

1. ทุกคนพิมพ์ **ชื่อ** และ **รหัสห้องเดียวกัน** (คนแรกที่เข้าจะเป็นหัวห้อง 👑)
2. หัวห้องเลือกหมวดหรือ 🎲 สุ่มหมวด แล้วกด "เริ่มเกม"
3. แต่ละคนได้คำลับไม่ซ้ำกัน — เห็นคำตัวเอง ส่วนคำของเพื่อนขึ้นเป็น `???`
4. ระบบ **สุ่มลำดับตาเล่น** ใหม่ทุกรอบ (แสดงแถบลำดับด้านบน) — ทายได้เฉพาะตอนถึงตาตัวเอง
   - ตาเรา: เลือกเพื่อน 1 คน → ถามใช่/ไม่ใช่ → เพื่อนกดตอบ → ทายคำของเพื่อนคนนั้นได้ 1 ครั้ง (หรือกด "🎯 ทายเลย" ไม่ต้องถาม / "จบตา")
   - คนตอบ/คนอื่น: กด "✅ จบตา ชื่อ…" (แตะ 2 ครั้ง) เพื่อส่งตาต่อได้เลย
   - ทายคำของเพื่อนถูก +2 (คำนั้นจะถูกเปิดให้ทุกคนเห็น และทายซ้ำไม่ได้)
   - จบรอบแล้วคำของใครยังไม่โดนทาย ได้โบนัสรอด +3
5. 💬 **แชท**: ถามใบ้ ตอบ ใช่/ไม่ใช่ ด้วยปุ่มลัด — ระบบจะไม่ให้พิมพ์คำลับของตัวเองหลุดในแชท
6. รอบจบเมื่อทุกคำโดนทายหมด หรือหัวห้องกด "จบรอบ" → เฉลยทั้งหมด แล้วเริ่มรอบใหม่ได้ คะแนนสะสมต่อ

หมวดที่มี 17 หมวด ~880 คำ: อาหารไทย, ขนมไทย, เครื่องดื่ม, จังหวัด (ครบ 77), ประเทศ, สถานที่, สัตว์, ผลไม้, ผัก, สิ่งของ, ยานพาหนะ, อาชีพ, กีฬา, อวัยวะร่างกาย, เครื่องดนตรี, สีและรูปทรง, ตัวละคร — แก้/เพิ่มได้ที่ `words.js`
(ใช้ `|` คั่นคำตอบที่ยอมรับ เช่น `'นครราชสีมา|โคราช'`)

## 🕵️ ใครคือสปาย (3 คนขึ้นไป)

1. ชาวบ้านได้คำเดียวกัน สปายได้คำคล้าย ๆ — **ไม่มีใครรู้ว่าตัวเองฝ่ายไหน**
   - สปาย 1 คน (3–5 คน), 2 คน (6–9 คน), 3 คน (10 คนขึ้นไป)
   - ตัวเลือก 🤍 **Mr. White** (5 คนขึ้นไป): ไม่ได้คำเลย ต้องเนียนเอา
2. **รอบใบ้**: ผลัดกันพิมพ์คำใบ้สั้น ๆ ตามลำดับ (ห้ามพิมพ์คำตัวเอง) — คำใบ้ทุกรอบโชว์บนการ์ดของแต่ละคน
3. **รอบโหวต**: แตะการ์ดคนที่สงสัย (เปลี่ยนใจได้) ครบทุกคน/หมดเวลา/หัวห้องกดปิดโหวต → คนที่ได้มากสุดออก และเปิดเผยฝ่าย (เสมอ = ไม่มีใครออก)
4. Mr. White โดนโหวตออก → ทายคำของชาวบ้าน 1 ครั้ง ถูก = ชนะคนเดียว
5. ชาวบ้านชนะเมื่อจับสปาย + Mr. White ได้หมด / ฝ่ายสปายชนะเมื่อเหลือเท่ากับหรือมากกว่าชาวบ้าน
6. คะแนน: ชาวบ้านชนะ +2 ทุกคน · สปายชนะ +5 · Mr. White ทายถูก +6 (รวมกับตารางคะแนนเดิม)

คู่คำอยู่ที่ `pairs.js` (~150 คู่) เพิ่มได้เลย

## ❓ ทายคำตรงกลาง (2 คนขึ้นไป)

1. หัวห้องเลือกหมวด → สุ่ม 1 คนเป็น 🎙️ **คนตอบ** (รอบต่อไปวนเปลี่ยนคน) เห็นคำลับคนเดียว
2. ที่เหลือผลัดกันตามลำดับ: ถามใช่/ไม่ใช่ 1 ข้อ → คนตอบกด ใช่/ไม่ใช่/อาจจะ → ทายได้ 1 ครั้ง หรือกด "🎯 ทายเลย" ไม่ต้องถาม
3. ทายถูก +3 (คนตอบ +1) · ถามครบ 20 ข้อแล้วไม่มีใครถูก → คนตอบ +3

## 🧀 หัวขโมยชีส (3 คนขึ้นไป)

1. ทุกคนกด 🎲 ทอยเต๋าลับ (เห็นเลขตัวเองคนเดียว) — สุ่ม 1 คนเป็น 🐀 หัวขโมย (6 คนขึ้นไปมี 🤝 ผู้สมรู้ร่วมคิด)
   - ทอยครบแล้วมีช่วง 👀 ดูเต๋า 10 วินาที ให้จำเลขตัวเองก่อนเข้ากลางคืน
2. 🌙 กลางคืน ตี 1 → ตี 6 (ตีละ 12 วินาที, ห้ามแชท) ใครทอยได้เลขไหนตื่นตีนั้น
   - ตื่นคนเดียว → แอบดูเต๋าของเพื่อนได้ 1 คน · ตื่นพร้อมคนอื่น → เห็นกัน
   - ขโมยขโมยชีสตอนตีของตัวเอง ใครตื่นตีเดียวกันเห็นขโมย · ขโมยชวนผู้สมรู้ร่วมคิดได้ตอนนั้น
3. ☀️ ตอนเช้า: ทุกคนเห็นบันทึกความทรงจำของตัวเอง คุยกันแล้วแตะการ์ดโหวต (เวลาคุย = 2 เท่าของเวลาต่อตา)
4. ขโมยได้โหวตมากสุด (รวมเสมอ) = หนูดีชนะ +2 ทุกคน · ไม่งั้นขโมยชนะ +4 (ผู้สมรู้ร่วมคิด +3)
5. จบเกมเฉลยเต๋าทุกคน + สิ่งที่เกิดขึ้นทุกตี

## 🎨 วาดภาพทายคำ (2 คนขึ้นไป)

1. ผลัดกันวาดคนละ 1 ตา: คนวาดเลือกคำจาก 3 ตัวเลือก (15 วินาที ไม่เลือก = เลือกให้)
2. วาดบนกระดาน (สี 8 สี, 3 ขนาด, ยางลบ, ย้อนกลับ, ล้างจอ) — คนอื่นเห็นเส้นแบบสด + ใบ้จำนวนตัวอักษรและหมวด
3. คนทายพิมพ์ในช่องทาย: ผิด = ขึ้นแชทให้ทุกคนเห็น / ถูก = ไม่โชว์คำ ประกาศแค่ "🎉 X ทายถูก!"
4. คะแนน: คนแรก +5, ถัดไป +4 … ต่ำสุด +1 · คนวาด +1 ต่อคนที่ทายถูก
5. จบตาเมื่อทุกคนทายถูก / หมดเวลา (เวลาต่อตา) / กดจบตา → เฉลยคำ 4 วินาที → คนถัดไป · วาดครบทุกคน = จบเกม
6. หัวห้องเลือกหมวดได้ ("สุ่ม" จะไม่เอาหมวดวาดยากอย่าง จังหวัด/ประเทศ)

## 🟥🟦 Codenames (4 คนขึ้นไป)

1. สุ่มแบ่ง 2 ทีมเท่า ๆ กัน + สุ่ม 🕶️ หัวหน้าทีมละ 1 คน — กระดาน 25 คำ: ทีมเริ่ม 9 ใบ, อีกทีม 8, กลาง 7, 💀 นักฆ่า 1
2. หัวหน้าเห็นสีการ์ดทุกใบ ใบ้ได้ **1 คำ + ตัวเลข** (ห้ามใช้คำบนกระดาน, หัวหน้าห้ามแชท)
3. ลูกทีมแตะการ์ด 2 ครั้งเพื่อเปิด ได้ไม่เกิน ตัวเลข+1 ใบ: สีตัวเอง = ทายต่อ / กลางหรือสีตรงข้าม = จบตา / 💀 = แพ้ทันที / กด "จบตา" เองได้
4. ทีมที่เปิดการ์ดสีตัวเองครบก่อนชนะ +3 ทุกคนในทีม · เวลาต่อตาใช้กับช่วงใบ้และช่วงเปิดการ์ด

## 🎲 เต๋าโกหก (2 คนขึ้นไป)

1. ทุกคนมีเต๋า 5 ลูก ทอยลับทุกรอบ (เห็นของตัวเองคนเดียว แตะเพื่อดู)
2. ตาเรา: ประกาศ "ทั้งโต๊ะมีเลข F อย่างน้อย Q ลูก" — ต้องสูงกว่าเดิม (จำนวนมากขึ้น หรือจำนวนเท่าเดิมแต่เลขสูงขึ้น)
   - ⚀ (เลข 1) เป็นไวลด์ นับเป็นทุกเลข และประกาศเลข 1 ไม่ได้
3. หรือกด **🤥 โกหก!** → เปิดเต๋าทุกคน: มีจริงครบ = คนกดเสียเต๋า 1 / ไม่ครบ = คนประกาศเสียเต๋า 1 — คนเสียเต๋าเริ่มรอบใหม่
4. เต๋าหมด = ตกรอบ · คนสุดท้ายชนะ +5 · อันดับ 2 +2
5. หมดเวลา: มีคนประกาศแล้ว → กดโกหกให้ / ยังไม่มี → ประกาศขั้นต่ำให้

## เล่นบนมือถือ

- ออกแบบให้เล่นในโทรศัพท์เป็นหลัก: ปุ่มใหญ่ แถบทายคำติดล่างจอ ไม่ซูมตอนพิมพ์
- คำลับของตัวเองเบลอไว้ แตะเพื่อดู/ซ่อน (กันเพื่อนที่นั่งข้าง ๆ แอบดู)
- กด 📤 ชวนเพื่อน เพื่อแชร์ลิงก์ห้อง (เปิดลิงก์แล้วรหัสห้องกรอกให้อัตโนมัติ)
- มือถือจะสั่นเมื่อทายถูก หรือเมื่อมีคนทายคำของเราถูก
- 🏆 ตารางอันดับคะแนนสะสมทุกรอบ (จบรอบแล้วจะขึ้นมาไว้บนสุด)

## รายละเอียดอื่น ๆ

- หลุด/ล็อกจอ/สลับแอป/รีเฟรช: กลับเข้าห้องเองอัตโนมัติ — ที่นั่ง คำ และคะแนนเก็บไว้ให้ 10 นาที (ยืนยันด้วยรหัสประจำเครื่อง จึงแย่งชื่อกันไม่ได้)
- ปิดจอ/ออกจากเกม = ขึ้น 💤 ถ้าถึงตาแล้วไม่กลับมาใน 30 วินาทีจะข้ามให้อัตโนมัติ (หรือเพื่อนกด "จบตา" ให้ก็ได้)
- เข้าห้องระหว่างรอบ: ได้คำที่ไม่ซ้ำกับคนอื่นทันที
- ทดสอบตรรกะเกม: `npm test`
